# Tutorial
Here’s how you can make your own IPA file without a Mac or iPad

# Step One: Fork this repository. On your screen you should see Fork click it and fork the repository.
# Step Two: replace every blank file with your own code. The only files are Info.plist App.swift (in Sources) and build.yml (in .github/workflows) and you can replace everything in them with your code.
# Step Three: once done, go to the actions tab (or click the more button and tap actions) and click build AppName. Once completed it’ll show you a check mark to download your IPA file go to actions tab the title (you cannot tap anything else except for the title) click structure and then download the file.
